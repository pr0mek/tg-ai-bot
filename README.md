# ИИ-бот для Telegram-группы (бесплатно)

Бот отвечает на вопросы и генерирует изображения через Google Gemini.
Реагирует на команды `/ask` и `/img`, а также на упоминание (@имя_бота) или ответ на его сообщение.

## Что нужно получить перед запуском

1. **Токен Telegram-бота** — через @BotFather (`/newbot`).
2. **Ключ Gemini API** — https://aistudio.google.com/apikey (бесплатно, без карты).

## Шаги для запуска на Railway (бесплатный хостинг)

1. Зарегистрируйся на https://railway.app через GitHub-аккаунт (если нет — создай на github.com, это бесплатно и быстро).
2. Создай новый пустой репозиторий на GitHub, загрузи туда все файлы из этой папки:
   - `bot.py`
   - `requirements.txt`
   - `Procfile`
3. В Railway: **New Project → Deploy from GitHub repo** → выбери свой репозиторий.
4. Зайди в настройки проекта → вкладка **Variables** → добавь две переменные:
   - `TELEGRAM_TOKEN` — вставь токен от BotFather
   - `GEMINI_API_KEY` — вставь ключ от Gemini
5. Railway сам установит зависимости и запустит бота (командой из Procfile).
6. Проверь логи (вкладка **Deployments → View Logs**) — там должна появиться строка "Бот запущен, ожидаю сообщения...".

## Добавление бота в группу

1. Добавь бота в свою Telegram-группу как обычного участника.
2. Напиши @BotFather → `/mybots` → выбери бота → **Bot Settings → Group Privacy → Turn off**
   (это нужно, чтобы бот видел упоминания и мог отвечать в группе, а не только на команды).
3. В группе напиши `/ask какой сегодня день` или упомяни бота — он должен ответить.

## Бесплатные лимиты

- Gemini API: бесплатный тариф даёт ограниченное количество запросов в минуту/день (лимиты может менять Google — актуальные цифры смотри на странице https://ai.google.dev/gemini-api/docs/rate-limits). Для небольшой группы обычно достаточно.
- Railway: бесплатный план даёт ограниченное количество часов работы в месяц. Если закончится — можно попробовать Render.com (тоже есть бесплатный тариф) с той же самой структурой файлов.

## Если что-то не работает

- Проверь логи в Railway — там будет видна конкретная ошибка.
- Частая причина: неверно скопированный токен (лишний пробел).
- Если бот не видит сообщения в группе — проверь, что Group Privacy выключен (шаг 2 выше).
